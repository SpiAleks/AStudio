# AStudio

## Тема проекта
Сервис по оказанию услуг графического дизайна

## Описание
Минималистичный лендинг для онлайн-сервиса графического дизайна.

Пользователь может:

- узнать о сервисе
- посмотреть услуги
- прочитать отзывы
- заказать дизайн

## Использованный CSS-фреймворк
Bulma

## Структура лендинга

- Header (навигация)
- Hero-секция
- О сервисе
- Услуги
- Отзывы
- CTA-блок
- Footer (контакты и соцсети)
